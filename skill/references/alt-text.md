# Drafting alt text the author can confirm in one glance

Alt text is Route 2 every time. The tool can see that it is missing; it cannot know what the
image is for in this course. You draft; the author confirms. These are the rules for the draft.

## The one question

**What would a student lose if this image were gone?** The answer, in one sentence, is the alt
text. If the answer is "nothing," the image is decorative and gets an empty alt attribute, not a
description.

## Four kinds of image, four shapes of draft

| Kind | Example | Draft shape |
| :--- | :--- | :--- |
| **Informative** | A photo of lab equipment the student must recognise | What it is and the detail that matters: *"Bunsen burner with the air hole half open, blue flame."* |
| **Data-bearing** | A chart, a graph, a table pasted as a picture | The finding, not the format: *"Enrollment rose from 1,200 to 1,900 between 2019 and 2025, with the steepest rise in 2021."* Offer to add the full data as a table below the image |
| **Functional** | An icon that is also a link or a button | What it does: *"Open the week 3 reading list."* Never what it looks like |
| **Decorative** | A stock photo, a divider, a logo already named in text | Empty alt. Say so: *"Decorative — no alt text, marked decorative."* |

## Rules for the sentence

- One sentence. Under about 125 characters where the content allows it.
- Do not begin with "image of" or "picture of." The screen reader already says that.
- Do not repeat the caption. If the caption says it, the image is decorative or the alt text says
  something the caption does not.
- Text inside the image goes into the alt text verbatim, or the image is replaced with text.
- Mathematical and chemical notation is written out as it would be spoken.
- Context decides. The same photograph is informative in a chemistry lab manual and decorative
  on a title slide.

## How to present drafts

Batch them. One table for the file:

| Location | What the tool saw | DRAFT alt text | Or decorative? |
| :--- | :--- | :--- | :-: |

Label every entry DRAFT. Put the decorative option in the last column wherever it is plausible.
Ask the author to mark each row **keep**, **edit** or **decorative**. Only then is anything
written into the file, and the file records that a person confirmed it.

## What you never do

- Never write alt text for an image you have not seen or had described. "Figure 3" is not a
  description. Ask the author what the image shows.
- Never let a model's description stand as final. The best models in published tests reach
  around 0.70 accuracy on alt text quality and sometimes describe things that are not in the
  image. That is why the author confirms.
- Never describe a data image by its appearance ("a bar chart with blue bars"). Describe what it
  shows.
